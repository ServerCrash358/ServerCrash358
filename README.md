     SETUP: SNAKE CONTRIBUTION GRAPH (GitHub Action)
     ------------------------------------------------------------
     1. In your profile repo (ServerCrash358/ServerCrash358),
        create the file:  .github/workflows/snake.yml
     2. Paste this:

        name: Generate Snake
        on:
          schedule:
            - cron: "0 */12 * * *"   # twice a day
          workflow_dispatch:
          push:
            branches: [main]
        jobs:
          generate:
            runs-on: ubuntu-latest
            permissions:
              contents: write
            steps:
              - uses: Platane/snk@v3
                with:
                  github_user_name: ${{ github.repository_owner }}
                  outputs: |
                    dist/github-contribution-grid-snake-dark.svg?palette=github-dark
              - uses: crazy-max/ghaction-github-pages@v4
                with:
                  target_branch: output
                  build_dir: dist
                env:
                  GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

     3. Go to the repo's Actions tab → run "Generate Snake" once
        (workflow_dispatch). It creates an  output  branch with
        the SVG. The README image above will then render.
